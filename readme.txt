استودیوی سئوی هوشمند وردپرس: تحلیل محتوا، نقشه سایت، ریدایرکت، اسکیما، ردیاب رتبه، خودکارسازی و هوش مصنوعی — همه در یک برنامهٔ تک‌صفحه‌ای فارسی.

== Description ==

هوش‌سئو یک افزونهٔ جامع سئو است که به‌جای صفحه‌های پراکندهٔ پیشخوان، یک برنامهٔ کامل (Studio) در تب جدید باز می‌کند؛ راست‌به‌چپ، با فونت فارسی، حالت تیره/روشن، و میان‌بُرها.

= آنچه به دست می‌آورید =

* **استودیو محتوا** — فهرست نوشته‌ها با امتیاز سئو، بررسی خودکار دسته‌ای، و درِ جزئیات برای هر نوشته: عنوان، توضیحات متا، کلمات کلیدی، پیش‌نمایش نتیجهٔ جست‌وجو (دسکتاپ/موبایل) و لیست بررسی‌ها با دکمهٔ «اصلاح با هوش مصنوعی».
* **تحلیل زنده** — چگالی کلمه کلیدی، طول عنوان و توضیحات، خوانایی، جمله‌های بلند، ساختار سرتیترها، لینک داخلی/خارجی، تصویر بدون متن جایگزین.
* **قالب عنوان‌ها** — الگوی ساخت عنوان برای خانه، نوشته، برگه، بایگانی، برچسب، نویسنده و تاریخ با متغیرهایی مثل `[[title]]`، `[[sep]]`، `[[excerpt]]`، `[[keyword]]`.
* **نقشه سایت XML** — چندنقشه‌ای، کش، اعلام خودکار به گوگل/بینگ، و رد کردن هر نوع محتوا.
* **ریدایرکت‌ها** — ۳۰۱/۳۰۲/۳۰۷/۴۱۰/۴۵۱، الگوی منظم (regex)، گروه‌بندی، تست مسیر، درون‌ریزی CSV، و شمارش بازدید.
* **پایش ۴۰۴** — چه نشانی‌ای، از چه مراجعی، چند بار، توسط چه رباتی؛ با ساخت ریدایرکت تک‌کلیکی.
* **لینک داخلی** — قاعده‌محور: یک بار کلمه و مقصد را تعریف می‌کنید، افزونه در بقیهٔ نوشته‌ها لینک می‌سازد؛ به‌علاوه پیشنهاد لینک، درج گروهی و گزارش لینک‌های شکسته.
* **ایندکس‌بان** — noindex گروهی روی نوشته‌ها و بایگانی‌ها، با «بازگردانی آخرین دسته» و اینکس‌ناو.
* **اسکیما** — Article، Product، FAQ، HowTo، LocalBusiness، Person، Organization، VideoObject و ساخت دایرکتوری محلی؛ با پیش‌نمایش JSON-LD و اعتبارسنجی.
* **تصویرها** — متن جایگزین خودکار (یا با هوش مصنوعی)، تغییر نام فایل هنگام بارگذاری، حذف EXIF، بارگذاری تنبل و پیش‌بارگذاری تصویر LCP.
* **سرعت** — کوچک‌سازی HTML، CSS بحرانی، به تعویق انداختن JS، حذف نسخه، کش صفحه، Heartbeat؛ با تخمین بایت صرفه‌جویی‌شده و اتصال PageSpeed.
* **کلمات کلیدی** — تحقیق از ۱۳ منبع (گوگل سرچ، یوتیوب، آپارات، ویکی‌پدیا، reddit، AnswerThePublic و…) و ردیاب رتبه با نمودار روند.
* **سرچ کنسول و آنالیتیکس** — اتصال OAuth یا کلید سرویس یا درون‌ریزی CSV؛ کلیک، بازدید، نرخ، رتبه، پرس‌وجوها و هشدارهای افت.
* **موتورهای پاسخ (GEO)** — `llms.txt`، `llms-full.txt`، جعبه پاسخ، Speakable، راهنمای خزنده، مسدودسازی یا اجازه به ربات‌های هوش مصنوعی.
* **ووکامرس** — سلامت کاتالوگ (GTIN، برند، توضیح کوتاه، تصویر، alt)، اسکیما محصول، noindex روی سبد خرید و پایان‌چین.
* **خلبانی سئو (Autopilot)** — کارهای زمان‌بندی‌شده در دو حالت «پیشنهاد» (بدون تغییر سایت) یا «اعمال»؛ هر تغییر قابل بازگردانی است.
* **هوش مصنوعی** — اتصال به OpenAI، Claude، Gemini، DeepSeek، Groq، Mistral، Perplexity، Cohere، Ollama محلی یا هر سرویس سازگار با OpenAI؛ سقف هزینه ماهانه، صف، کش و گفت‌وگوی سئویی.
* **ممیزی و بازگردانی** — هر تغییری با «پیش/پس» ثبت می‌شود و تک‌کلیکی برگردانده می‌شود.
* **گزارش آمادهٔ چاپ** — یک بریده‌مفید از وضعیت سایت، قابل ایمیل و دانلود CSV.

هیچ داده‌ای به سرور ما فرستاده نمی‌شود. همه‌چیز روی هاست خودتان است.

== Installation ==

1. از پیشخوان → افزونه‌ها → «افزودن جدید» → «بارگذاری افزونه»، فایل `hoosh-seo.zip` را بارگذاری کنید.
2. «فعال‌سازی» را بزنید؛ جدول‌ها خودکار ساخته می‌شوند.
3. از منوی «هوش‌سئو» استودیو را باز کنید و اتصال هوش مصنوعی را (اختیاری) تنظیم کنید.
4. راهنمای کامل نصب، حداقل‌های سرور و عیب‌یابی: `docs/INSTALL.md` (در استودیو → راهنما هم قابل خواندن است).

نکته: اگر ZIP را مستقیم از گیت‌هاب می‌گیرید، فایل اصلی افزونه باید دقیقاً یک پوشه زیر ریشهٔ ZIP باشد؛ در غیر این صورت وردپرس پیام «افزونهٔ معتبر یافت نشد» را نشان می‌دهد.

== Frequently Asked Questions ==

= آیا با Yoast یا Rank Math می‌تواند هم‌زمان فعال باشد؟ =
پیشنهاد نمی‌شود. هوش‌سئو هنگام فعال بودن، افزونهٔ سئوی دیگر را تشخیص می‌دهد و هشدار می‌دهد؛ می‌توانید داده‌های آن‌ها را یک‌بار با بخش «مهاجرت» منتقل کنید.

= آیا برای نوشتن محتوای جدید حتماً به هوش مصنوعی نیاز است؟ =
نه. همهٔ بررسی‌ها، لینک داخلی، نقشه سایت و ردیابی رتبه بدون هوش مصنوعی کار می‌کنند.

= داده‌ها کجا ذخیره می‌شوند؟ =
در ۱۴ جدول اختصاصی با پیشوند `wp_hoosh_` و در `postmeta` با کلیدهای `_hs_*`.

= چطور همه‌چیز را پاک کنم؟ =
در تنظیمات → عمومی گزینهٔ «حذف داده‌ها هنگام حذف افزونه» را روشن کنید، سپس افزونه را حذف کنید.

= سایت کند شد! =
استودیو → سرعت → «اعمال همهٔ تیک‌های بی‌خطر» و بعد پاک کردن کش. برای گزارش دقیق‌تر، ابزارها → «کپی گزارش» را برای ما بفرستید.

== Environment ==

* WordPress 5.8 یا بالاتر، PHP 7.3 یا بالاتر (با PHP 8.x آزمون شده)، MySQL 5.7 / MariaDB 10.2.
* افزونه بدون `curl` هم کار می‌کند (از stream wrapper استفاده می‌کند)، ولی `curl` توصیه می‌شود.
* برای گزارش سرعت، کلید PageSpeed اختیاری است.
